## Recomendaciones Iniciales:

### 1. **Implementar Batch Queries**:
```dart
// MAL: Query por cada usuario
for (var userId in userIds) {
  var userDoc = await FirebaseFirestore.instance
      .collection('users')
      .doc(userId)
      .get();
}

// BIEN: Batch query
var userDocs = await FirebaseFirestore.instance
    .collection('users')
    .where(FieldPath.documentId, whereIn: userIds)
    .get();
```

### 2. **Cachear Datos de Usuario**:
Extender `UserCacheService` para cachear datos frecuentemente accedidos.

### 3. **Optimizar Listeners**:
Consolidar listeners en lugar de tener uno por chat.

### 4. **Usar Field Selectivity**:
Solo obtener los campos necesarios:
```dart
// En lugar de .get()
```
