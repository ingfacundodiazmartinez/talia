### 1. **Problema Principal: N+1 Queries en `ChatRetrievalService`**

En `/Users/olagg/Personal/talia/lib/services/chats/services/chat_retrieval_service.dart`:

```dart
/// Obtener información de un chat específico
Future<Chat?> getChatInfo(String chatId) async {
  try {
    final doc = await _chatRepository.getChatById(chatId); // ⚠️ Query individual por cada chat
    if (doc != null && doc.exists) {
      final data = doc.data() as Map<String, dynamic>;
      return Chat(
        id: doc.id,
        type: data['type'] ?? 'individual',
        name: data['name'] ?? '',
        participants: List<String>.from(data['participants'] ?? []),
        lastActivity: (data['lastActivity'] as Timestamp?)?.toDate() ?? DateTime.now(),
        unreadCount: data['unreadCount'] ?? 0,
      );
    }
    return null;
```

## 🎯 **Patrones Comunes de Queries No Performantes**

1. **N+1 Queries**: Obtener datos de múltiples documentos uno por uno en lugar de usar `whereIn()`
2. **Filtrado en Cliente**: Traer muchos documentos y filtrar localmente en lugar de usar queries de Firestore
3. **Límites Altos**: Usar `limit(200)` cuando solo se necesitan 50 resultados
4. **Falta de Índices**: No usar campos indexados para búsquedas
