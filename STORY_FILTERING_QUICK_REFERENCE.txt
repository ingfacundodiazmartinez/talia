==============================================================================
THREE TYPES OF CONTACTS
==============================================================================

1. Approved Bidirectional Contacts
   - Both users must explicitly approve
   - Stored in 'contacts' collection with status='approved'
   - Can see each other's APPROVED stories only
   
2. Linked Children (Parent -> Child)
   - Parent can see ALL story statuses from child
   - Stored in user.linkedChildrenIds array
   - One-directional: parent has authority
   
3. Linked Parents (Child -> Parent)
   - Child can see parent's APPROVED stories only
   - Found by querying: users where linkedChildrenIds contains child
   - Reverse of linked children

COMBINED: All three are merged into one "contacts" set

==============================================================================
STORY VISIBILITY RULES
==============================================================================

CAN SEE:
✓ Own stories (any status)
✓ Approved contact's APPROVED stories
✓ Child's ANY status stories (if parent)
✓ Parent's APPROVED stories (if child)
✓ If no block exists between users
✓ If story not expired (>24 hours)

CANNOT SEE:
✗ Non-contact's stories
✗ UPLOADING status stories (except creator)
✗ Expired stories
✗ REJECTED/PENDING stories from non-parents
✗ ARCHIVED stories
✗ Stories from blocked users
✗ Stories via GROUP membership (GROUPS DON'T COUNT)

==============================================================================
QUICK REFERENCE: WHO SEES WHAT
==============================================================================

Regular User (Child):
  Can see:
    - Own stories (all statuses)
    - Approved contact stories (status=APPROVED only)
    - Parent stories (status=APPROVED only)
  Cannot see:
    - Non-contact stories
    - Pending/rejected stories from others
    - Stories from blocked users
    - Group member stories (unless also contact/parent)

Parent User:
  Can see:
    - Own stories (all statuses)
    - Child stories (ALL statuses: approved, pending, rejected)
    - Approved contact stories (status=APPROVED only)
  Cannot see:
    - Non-contact stories
    - Stories from blocked users

==============================================================================
FIRESTORE COLLECTIONS INVOLVED
==============================================================================

users/
  ├─ id: userId
  ├─ linkedChildrenIds: [array of child IDs]
  └─ ... (other user fields)

contacts/
  ├─ id: auto
  ├─ users: [userId1, userId2]
  ├─ status: "approved" | "pending" | "rejected"
  └─ ... (timestamps, names, etc)

stories/
  ├─ id: auto
  ├─ userId: creatorId
  ├─ status: "approved" | "pending" | "rejected" | "uploading"
  ├─ visibility: "temporary" | "permanent" | "archived"
  ├─ expiresAt: timestamp
  └─ ... (media, captions, etc)

blocked_contacts/
  ├─ id: "userA_userB"
  └─ (prevents A and B from seeing each other's stories)

groups/
  ├─ id: auto
  ├─ members: [userId1, userId2, ...]
  └─ ... (group chat data, NOT story visibility)
